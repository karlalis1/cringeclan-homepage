# Quick Start Guide - Karlali Landing Page

Schneller Einstieg in deine neue Landing Page.

## ⚡ 5-Minuten Quick Start

### 1. Öffnen
Doppelklick auf `index.html` - fertig! 🎉

### 2. Admin-Panel testen
- Klicke oben rechts auf "Admin"
- Passwort: `333`
- Erstelle dein erstes Projekt

### 3. Theme wechseln
- Klicke auf das Mond/Sonne Icon in der Navigation
- Probiere Dark, Light und High-Contrast Mode

### 4. Projekte hinzufügen
- Im Admin-Panel: "Projekt hinzufügen"
- Fülle die Pflichtfelder aus
- Klicke auf "Projekt hinzufügen"

### 5. Daten sichern
- Im Admin-Panel auf "Export" klicken
- JSON-Datei wird heruntergeladen
- Bewahre diese als Backup auf

## 🆘 HILFE BEI PROBLEMEN

### Seite lädt nicht
- Browser aktualisieren (F5)
- Console prüfen (F12)
- Dateipfade prüfen

### Admin-Panel geht nicht
- Passwort prüfen (Standard: 333)
- Browser Console prüfen
- localStorage aktiviert?

### Projekte nicht sichtbar
- Filter prüfen
- Suchfeld leeren
- Browser aktualisieren

### Theme wechselt nicht
- JavaScript aktiviert?
- Console prüfen
- localStorage aktiviert?
